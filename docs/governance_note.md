# Governance note

This repository is a public portfolio demonstration built from invented records. It does not use, copy or claim access to ECHILD, HES, NPD or children's social-care records.

The public Streamlit app displays aggregate outputs only. It does not display child-level records, provide row-level downloads or expose free-text SQL. Non-zero counts below a configurable threshold are suppressed using an illustrative rule.

The suppression rule is a portfolio example. It does not claim to reproduce ONS SRS output-checking rules. A production workflow would follow the approved environment's governance procedures, data-access agreements, project approvals, training requirements and output-checking process.
